# Amazon-Fresh-Retail-Sales-Analysis
This project develops a structured SQL database for Amazon Fresh and performs comprehensive sales analysis. It focuses on organizing retail data efficiently and extracting valuable insights related to customer orders, product performance, sales trends, regional demand, discounts, and delivery operations.
