# Amazon Fresh Retail Sales Analysis
Amazon Fresh Sales Analysis is an end-to-end data analytics project that combines SQL and Microsoft Power BI to transform retail data into meaningful business insights. The project involves designing a structured relational database, performing SQL-based sales analysis, and developing interactive Power BI dashboards to evaluate customer behaviour, product performance, inventory status, and regional sales trends.

Project Highlights
* Designed and implemented a structured relational database using MySQL.
* Performed SQL analysis using joins, aggregate functions, subqueries, normalization, and business queries.
* Integrated the SQL database with Microsoft Power BI for interactive reporting and visualization.
* Developed dashboards to analyze sales performance, product insights, customer behaviour, inventory, discounts, and regional trends.
* Analyzed business performance with approximately ₹27 million in total revenue, ₹25 million in total order value, and 55,000 units sold.
* Identified high-performing products, customer purchasing patterns, and regional sales opportunities through interactive visualizations.
* Delivered actionable business insights to improve operational efficiency, optimize inventory management, and support data-driven decision-making.
* Demonstrated practical expertise in SQL, database design, data modeling, business analytics, and Power BI dashboard development.
